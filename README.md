## Netlify Deployment Guide
1. Open the folder in VS Code.
2. Create a GitHub repository.
3. Push the full folder to GitHub.
4. In Netlify, choose **Add new site → Import from Git**.
5. Select your repository.
6. Because this is static HTML, leave build command empty.
7. Set publish directory to `/` or leave default.
8. Deploy.

## Custom Domain Setup for ALLASCAR_Tech.com
1. Buy or manage the domain with your registrar.
2. In Netlify, open **Site settings → Domain management**.
3. Add `ALLASCAR_Tech.com` and `www.ALLASCAR_Tech.com`.
4. Use Netlify DNS or copy Netlify DNS records into your registrar.
5. Wait for DNS propagation.
6. Enable HTTPS in Netlify.
